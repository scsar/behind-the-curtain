# 막 너머의 사람들

**가제:** 막 너머의 사람들  
**프로젝트 코드명:** Behind the Curtain  
**상태:** 콘셉트 기획 단계

> 사람들의 삶까지 각본대로 움직이려는 인형사에 맞서, 동료와 함께 조종의 실을 끊는 온라인 RPG.

Unity 기반 1인 개발 프로젝트. 클라이언트·서버 포트폴리오와 실제 출시를 목표로 한다. 소수 인원이 이용하는 작은 온라인 세계에서 시작하고, 지역 및 수용 인원 확장을 검토한다.

## 핵심 콘셉트

- 자신의 무기와 기술로 직접 싸우는 역할 기반 협동 PvE.
- 플레이어의 전술에 대응을 바꾸는 인형사와 적 인형 파티.
- 합동 공격의 전조에 드러나는 조종 실을 끊는 카운터.
- 공유 공간에서의 만남, 생활, 지속되는 캐릭터 성장.

## 개발 방식

코드는 격리된 실행기 **jevcode**(`C:\Github\jevcode`)로 에이전트에게 맡기고, 사람이 리뷰해 수락·커밋한다. 실행 기록은 판단 모델 평가에도 쓰인다. 흐름과 규칙은 위의 전체 개요와 `docs/next-runs.md`에 있다.

## 개발 상태

규칙 코어(`src/Core`, 테스트 300개 이상)와 Unity 쿼터뷰 프로토타입(`Assets/Scripts/Prototype`)이 동작한다. 카운터, 압박, 연출가의 적응, 인형 AI까지 화면에서 확인했다. 서버 코드, 최종 파티 정원(4~5인 목표), 네트워크 기술, 개발 일정은 미정이다.

게임 제목과 영문 코드명은 작업용 가명이다.
