프로토타입(Unity)에서 인형마다 결(T16b-3b-1: 대담 ↔ 신중, 집착 ↔ 변덕)을 주고, 결이 Play에서 보이게 한다. src/Core는 바꾸지 않는다(필요한 API가 없으면 고치지 말고 제안 섹션에 적는다). 씬·프리팹·에셋 파일은 만들지 않는다. 판정, 충돌, 연결부, 바닥 경고, 루트 Transform은 바꾸지 않는다(U8과 같은 원칙: 표시는 'Marionette' 자식만).

1) 결 부여: 교전 시작 때 InitializeBrain에서 배역 배분 뒤, PuppetBrain을 만들기 전에 인형마다 `World.SetTemperament`로 결을 넣는다. PrototypeSettings에 `TemperamentMode`(기본 Random)를 둔다:
   - Random: 축마다 −1 ~ 1 균등. 시드는 settings.Seed, 교전 번호, AgentId로 만든 Core의 DeterministicRandom(System.Random 금지). 값은 소수 첫째 자리로 반올림한다(읽기 쉽게). 같은 Seed면 같은 교전 번호의 같은 인형은 늘 같은 결이다.
   - Off: 모든 축 0(이 run 전과 같은 행동).
   - Manual: PrototypeSettings의 인형 자리 4개마다 대담·집착 값(기본 0, −1 ~ 1로 자름).
   SetTemperament가 거부하면 프로토타입을 멈추지 않고 경고(U7의 경고와 같은 방식) 뒤 그 인형은 0으로 둔다.
2) 비교 토글: F3을 누르면 지금 교전에서 결을 끈 상태(모두 0)와 지금 모드의 결을 오간다. 바꾼 뒤 F5와 같은 방식으로 PuppetBrain을 다시 만든다(같은 World, 위치·상태·장비·배역 유지). 조작 안내에 F3을 더한다. F2(상자/마리오네트)처럼 같은 Play에서 결의 차이를 번갈아 보려는 것이다.
3) 보이는 단서(시각만, 'Marionette' 자식만):
   - 대담 ↔ 신중: 모든 자세의 바탕에 기울기를 더한다. b > 0이면 몸통을 앞으로 b × BoldLeanAngle(기본 10도) 숙이고 가슴을 내민다. b < 0이면 몸을 −b × CautiousCrouch(기본 0.06) 낮추고 뒤로 −b × CautiousLeanAngle(기본 6도) 젖히며 무기 팔을 몸 앞으로 조금 든다(경계 자세). 이동·견제·공격·막아서기 자세는 이 바탕 위에 더한다.
   - 대상 보기(모든 인형): 머리를 결정의 대상(Target) 쪽으로 돌린다(몸 정면에서 좌우 HeadTurnLimit 기본 70도까지, PoseBlendSeconds로 섞음). 대상이 없으면 정면. 그래서 변덕스러운 인형이 대상을 바꾸는 순간이 비틀거림 없이 고개가 먼저 돌아가는 것으로 보인다(장력 저하의 비틀거림과 구별되는 단서).
4) F1 오버레이: 인형 라벨에 '결 대담 +0.6 / 집착 −0.3'처럼 두 축 값을 한 줄로 더한다. 맨 위 줄에 결 모드(Random/Off/Manual)와 F3 상태(켜짐/꺼짐)를 더한다.
수치는 PrototypeSettings에 새 필드로 두고 임의로 정한 값임을 표시한다. 기존 기본값은 바꾸지 않는다. 사람이 할 일에 PrototypeBootstrap Reset이 필요한지 적는다.
규칙 코어 테스트(dotnet test tests/Core.Tests --no-restore -m:1)는 계속 통과해야 한다.
마지막 메시지에 '검증 근거' 표: 1)~4) 각각 바꾼 파일과 메서드, 결 Random의 시드 구성, 3)의 결 값 → 바뀌는 부위와 각도 표.

## 리뷰 포인트
- [리뷰 화면] 변경 파일 → Assets/Scripts/Prototype 아래만 있고 src/ 아래와 .unity·.prefab·.asset 파일이 없다
- [리뷰 화면] 검증 → dotnet test passed, unity recompile passed(에디터를 열어 두고 돌렸을 때)
- [Play] F1을 켜고 교전 1 → 인형마다 결 값이 라벨에 보이고, 같은 Seed로 다시 Play하면 같은 값이다
- [Play] 대담 값이 큰 인형과 신중 값이 큰 인형을 찾아 대기 자세를 본다 → 대담은 앞으로 숙이고, 신중은 낮추고 젖혀 무기를 몸 앞에 든다
- [Play] 막아서기를 유도한다 → 대담한 방패 인형이 신중한 쪽보다 위협 쪽으로 더 나가 막는다
- [Play] 사람을 두고 인형 주위를 돈다 → 인형들의 머리가 대상 쪽을 본다
- [Play] F3으로 결을 껐다 켰다 한다 → 꺼지면 대기 자세와 막아서는 위치가 모두 같아지고, 켜면 다시 갈린다
- [Play] TemperamentMode를 Off로 두고 교전 1 → U9 전과 같은 행동이다(결 표시는 모두 0)
