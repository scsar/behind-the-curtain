src/Core.Sim의 인형 시뮬레이션에 '고정 경로로 움직이는 플레이어 둘' 시나리오와 대상 분포 지표를 더한다. 새 행동(측면 돌기, 포위, 견제)을 넣기 전에, 플레이어가 둘일 때 지금의 인형들이 누구를 노리고 누구를 막는지 기준선을 만드는 run이다. 학습은 없다. src/Core의 행동 규칙은 바꾸지 않는다(필요한 읽기 전용 노출만 추가 가능). Unity 코드는 바꾸지 않는다.

1) 플레이어 둘: 시나리오가 플레이어 개체를 둘(AgentId 1과 2, 둘 다 사람, Side.Players) 넣을 수 있게 한다. 기존 일곱 시나리오는 지금처럼 플레이어 하나(AgentId 1)다.
2) 새 시나리오 둘(--puppets):
   duo = A(1)는 파티 정면 (0, 12)에서 5m/s로 (0, 4)까지 와서 멈춘다. B(2)는 파티 오른쪽 옆 (9, -1)에 서서 움직이지 않는다. 힐러 위협 기억은 B에게 있다(healer 시나리오처럼 지난 교전에서 B가 힐러를 노린 관찰 하나를 넣는다. 공격자 id만 2로).
   duo-swap = duo와 같이 시작하고, 5초에 A와 B가 위치를 바꾸는 경로로 움직인다(A는 (9, -1)로, B는 (0, 4)로, 각자 5m/s 직선). 힐러 위협 기억은 그대로 B에게 있다.
3) 대상 분포 지표(시나리오 끝 출력, 플레이어가 둘일 때만): 플레이어마다 '그 플레이어를 대상(Target)으로 삼은 인형-tick 수'와 비율. '대상이 있는 tick 중 힐러가 아닌 인형 모두가 같은 플레이어를 대상으로 삼은 tick의 비율'(몰림 비율). intercept가 어느 플레이어를 막았는지(intercept의 대상 id별 tick 수).
4) 기존 금지 패턴 지표와 위치 떨림, 막아서기 품질은 새 시나리오에도 그대로 출력한다.
수치(위치, 속도, 시간)는 시나리오 설정에 두고 임의로 정한 값임을 표시한다.
테스트: (a) 기존 일곱 시나리오의 궤적은 이 run 전과 같다. (b) duo, duo-swap에서 기존 금지 패턴과 위치 떨림이 통과한다. (c) duo에서 intercept의 대상은 B(2)다(힐러 위협자). (d) duo-swap에서 위치를 바꾼 뒤에도 intercept의 대상은 B(2)이고, 막아서는 개체가 B의 새 위치 쪽 선분으로 옮겨 간다(바꾼 뒤 2초 안에 선분 1.0m 이내). (e) 대상 분포 지표의 합이 맞다(플레이어별 tick 합 = 대상이 있는 인형-tick 수). (f) 결정론. 규칙 코어 테스트는 계속 통과해야 한다.
마지막 메시지에 '검증 근거' 표를 둔다: 1)~4)와 테스트 (a)~(f) 각각의 테스트 이름이나 출력 줄. 그리고 아래 두 출력의 끝 지표 줄(금지 패턴, 막아서기 품질, 대상 분포)을 그대로 붙이고, 지금의 인형들이 두 플레이어를 어떻게 나눠 노리는지 두세 문장으로 적는다.
dotnet run --project src/Core.Sim -- --puppets duo
dotnet run --project src/Core.Sim -- --puppets duo-swap

## 리뷰 포인트
- [리뷰 화면] 변경 파일 → src/Core 아래 행동 규칙 파일(PuppetActions, PuppetBrain, UtilitySelector)이 없다. 있으면 읽기 전용 노출만인지 diff에서 확인
- [시뮬레이터] `dotnet run --project src/Core.Sim -- --puppets duo` → 끝에 대상 분포 줄이 있고, 플레이어 1과 2의 비율 합이 100%, intercept 대상이 2
- [시뮬레이터] `dotnet run --project src/Core.Sim -- --puppets duo-swap` → intercept 대상이 끝까지 2이고, 5초 이후 10번의 intercept 위치가 B의 새 위치 쪽으로 옮겨 간다
- [시뮬레이터] `dotnet run --project src/Core.Sim -- --puppets approach` → 끝 지표 줄이 이 run 전과 같다(대상 분포 줄은 없다)
- [리뷰 화면] 삭제되거나 이름이 바뀐 테스트 → 0개
- [근거 표] '두 플레이어를 어떻게 나눠 노리는지' 설명 → 몰림 비율 숫자와 함께 적혀 있다
