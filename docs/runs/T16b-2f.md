src/Core의 막아서기(intercept)가 실제로 힐러와 위협자 사이를 따라가게 고친다. 지금은 막아서는 개체가 제자리에 멈춘다: `dotnet run --project src/Core.Sim -- --puppets healer`에서 Guard(10)가 105 tick 내내 intercept 상태로 (-1.50, 0.00)에 서 있고, 그동안 플레이어와 힐러는 움직인다. 원인은 PuppetActions.ConstrainMovement다. intercept의 목표 지점(힐러에서 위협자 쪽으로 InterceptDistance)이 개체보다 플레이어에게서 멀면, '위협 반경 안의 사람에게서 멀어지는 이동은 막는다' 규칙(T15r에서 이유 없는 도망을 막으려고 넣음)이 그 이동을 막아 개체가 멈춘다. 다른 행동 규칙은 바꾸지 않는다. Unity 코드는 바꾸지 않는다. 공개 API는 유지한다.

1) 막아서기 목표 지점: 힐러-위협자 선분 위에서 그 개체의 현재 위치에 가장 가까운 점으로 바꾼다. 단 선분의 힐러 쪽 끝에서 InterceptDistance(기본 1.5m)보다 힐러에 가깝지 않게, 위협자 쪽 끝에서 InterceptStandOff(기본 1.0m, 새 설정)보다 위협자에 가깝지 않게 자른다(선분이 이 둘의 합보다 짧으면 지금처럼 힐러에서 InterceptDistance 지점). 이렇게 하면 개체는 주로 옆으로 움직여 선 위에 선다.
2) 이동 제약: intercept는 '위협 반경 안의 사람에게서 멀어지는 이동 금지'에서 뺀다(spread, keepDistance처럼). 금지 패턴 '이유 없는 도망'의 판정에서도 intercept 중인 tick은 정당한 이유가 있는 이동으로 보고 센다에서 뺀다(docs/ai-design.md 금지 패턴 표의 '이유 없는 도망' 설명에 'intercept 중 선분으로 가는 이동은 제외'를 덧붙인다). 다른 행동(hold 포함)의 제약은 그대로다.
3) 시뮬레이션 지표: src/Core.Sim의 --puppets 출력 끝 금지 패턴 지표 옆에 '막아서기 품질'을 더한다: intercept 중인 tick 수, 그중 개체와 힐러-위협자 선분 사이 거리가 InterceptLineTolerance(기본 1.0m, 새 설정) 이하인 비율, 평균 거리. intercept를 시작한 뒤 처음 InterceptSettleTicks(기본 30 = 1초, 새 설정)는 이동 중이므로 비율 계산에서 뺀다.
수치는 설정에 두고 임의로 정한 값임을 표시한다.
테스트: (a) 원인 재현: 위 healer 시나리오에서 intercept 중인 개체가 1초 넘게 같은 위치에 머무르지 않는다(플레이어나 힐러가 움직이는 동안). (b) 막아서기 품질: healer와 circle 시나리오에서 intercept tick의 80% 이상이 선분에서 1.0m 이내(정착 시간 제외). (c) 목표 지점 경계: 개체가 선분 바로 옆에 있으면 목표가 그 수직 아래 점, 선분 끝 너머에 있으면 잘린 끝점(힐러에서 1.5m, 위협자에서 1.0m), 선분이 2.5m보다 짧으면 힐러에서 1.5m 지점. (d) 기존 금지 패턴: 네 시나리오와 --loadout mixed --cast, --loadout noprotect에서 진동, 군체 동기화, 겹치기, 무반응, 이유 없는 도망(위 제외 반영), 배역 수행 불능 시 정지가 모두 통과한다. (e) 결정론. 규칙 코어 테스트는 계속 통과해야 한다. intercept가 나오지 않는 시나리오의 궤적은 이 run 전과 같아야 한다(approach, retreat 시나리오 등). 궤적이 바뀐 기존 테스트가 있으면 무엇을 왜 바꿨는지 기존 동작 변경 섹션에 적는다.
마지막 메시지에 '검증 근거' 표를 둔다: 위 1)~3)과 테스트 (a)~(e) 각각에 해당하는 테스트 이름이나 출력 줄. 그리고 dotnet run --project src/Core.Sim -- --puppets healer 와 --puppets circle 출력의 Guard(10) 줄 몇 개와 막아서기 품질 지표를 적는다.

- [시뮬레이터] `dotnet run --project src/Core.Sim -- --puppets healer` → Guard(10)의 intercept 위치가 tick마다 바뀌고, 끝의 막아서기 품질 비율이 0.80 이상
