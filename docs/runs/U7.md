프로토타입(Unity)에서 인형 행동의 수치를 Play 중에 바꿔 보며 감각을 맞출 수 있게 한다. 지금은 Play 피드백("동작은 하는데 굼뜨고, 앞으로 살짝 왔다가 몇 초 뒤 물러나는 식으로 불연속적")을 고치려면 숫자 하나를 바꿀 때마다 jevcode run을 돌려야 한다. 이 run은 Core의 수치를 인스펙터에 연결만 한다. src/Core는 바꾸지 않는다(필요한 API가 없으면 고치지 말고 제안 섹션에 적는다). 기본값도 바꾸지 않는다: 인스펙터의 초깃값은 지금 Core의 기본값과 같아야 한다.

1) 조절 항목: PrototypeSettings에 'PuppetTuning' 묶음을 두고, Core의 PuppetSettings 생성자 인자와 BasicActionSettings 생성자 인자 중 숫자로 된 것을 모두 인스펙터 필드로 둔다(roleWeights 같은 표는 제외). 지금 PrototypeJointAttack.Brain.cs의 InitializeBrain이 PrototypeSettings에서 일부만 넘기고 있는데(PuppetInterceptDistance, PuppetMoveSpeed 등), 이것도 이 묶음으로 옮겨 하나로 합친다. 필드마다 [Tooltip]에 무엇을 바꾸는지와 Core 기본값을 적는다. 특히 감각에 직접 걸리는 것: ReevaluationIntervalTicks(판단 주기, 기본 30 = 1초), MoveSpeed, KeepDistanceSpeed, PersistenceBonus, WeightJitter, HarassIntervalTicks, HarassRecoverTicks, HarassMargin, FlankRadius, FlankAngle, FlankWeight, HarassWeight와 무기 선호 배율들.
2) 적용 시점: 교전이 시작될 때(InitializeBrain) 인스펙터 값으로 PuppetSettings·BasicActionSettings를 만든다. 그리고 F5를 누르면 지금 교전에 바로 다시 적용한다: 같은 World(위치, 상태, 장비, 배역 유지)로 PuppetBrain을 새로 만든다. 이때 진행 중이던 판단은 처음부터 다시 시작해도 된다.
3) 잘못된 값: Core가 설정을 거부하면(PuppetBrain.Create 실패) 지금처럼 프로토타입을 멈추지 말고, 화면 왼쪽 위에 경고를 3초 띄우고 Console에 Warning을 남긴 뒤 이전 설정을 그대로 쓴다. 교전 시작 때 거부되면 Core 기본값으로 시작하고 같은 경고를 띄운다.
4) 값 기록: F6을 누르면 지금 적용 중인 값 중 Core 기본값과 다른 것만 'Name=Value' 형식 한 줄로 Console에 Log로 남기고, 클립보드(GUIUtility.systemCopyBuffer)에도 복사한다. 다른 값이 없으면 '기본값과 같음'.
5) 표시: F1 오버레이 맨 위에 판단 주기, 이동 속도, 견제 주기·회복, 측면 돌기 반경과 '기본값과 다른 항목 수'를 한 줄로 보여 준다.
6) 조작 안내: 화면의 조작 안내에 F5(수치 다시 적용), F6(수치 기록)을 더한다.
사람이 할 일에 'PrototypeBootstrap 컴포넌트 Reset'이 필요한지 적는다. 규칙 코어 테스트(dotnet test tests/Core.Tests --no-restore -m:1)는 계속 통과해야 한다(Core를 바꾸지 않으므로 그대로여야 한다).
마지막 메시지에 '검증 근거' 표를 둔다: 1)~6) 각각 바꾼 파일과 메서드 이름, 그리고 인스펙터에 둔 필드 목록(이름, Core 기본값, 인스펙터 초깃값)을 표로 적는다. 두 값이 다른 필드가 있으면 그 이유를 적는다.

## 리뷰 포인트
- [리뷰 화면] 변경 파일 → src/Core 아래 파일이 없다
- [근거 표] 필드 목록 표 → 모든 필드의 Core 기본값과 인스펙터 초깃값이 같다
- [Play] 아무것도 바꾸지 않고 교전 1을 한다 → 이 run 전과 같은 행동(F6을 누르면 '기본값과 같음')
- [Play] 인스펙터에서 판단 주기를 30에서 10으로 바꾸고 F5 → 인형들의 반응이 눈에 띄게 빨라진다
- [Play] KeepMax를 KeepMin보다 작게 바꾸고 F5 → 경고가 뜨고 게임이 멈추지 않으며 이전처럼 움직인다
- [Play] 값을 두어 개 바꾸고 F6 → Console에 바꾼 항목만 한 줄로 나오고, 메모장에 붙여 넣으면 같은 줄이 나온다
- [Play] F1 → 맨 위에 판단 주기와 '기본값과 다른 항목 수'가 보인다
